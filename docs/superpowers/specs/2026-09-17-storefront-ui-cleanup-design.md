# Storefront UI 整理（港式電商化 + 左欄摺疊分類）

## 目標

- 將現有前台由「資訊堆疊、分類重覆、三欄過重」整理成較接近香港電商站的清晰導購版面。
- 保留左欄分類入口，但改成摺疊式樹狀導覽，避免一入頁就見到大量分類。
- 首頁只負責導購與活動曝光；商品列表頁才承擔完整分類瀏覽與篩選。
- 商品詳情頁減少干擾，將焦點集中在商品資訊與購買區。

## 已確認方向

- 視覺取向：`港式電商化`
- 分類取向：`保留左側分類，但做摺疊式`
- 全站策略：採用整理方案 `B`

## 現況問題

- `views/partials/header.ejs`
  - 同時存在 top utility bar、搜尋列、下方橫向分類列，分類資訊重覆出現多次。
- `views/partials/sidebar-left.ejs`
  - 左欄同時混合商品分類、會員區、公告圖，資訊目的不單一。
- `views/partials/sidebar-right.ejs`
  - 最近瀏覽與推薦模組長期常駐，令首頁、列表頁、詳情頁右側持續搶焦點。
- `views/index.ejs`
  - 首頁沿用左右欄加中間內容，banner、排行榜、最新上架都似主內容，主次不清。
- `views/products.ejs` / `views/product.ejs`
  - 雖然內容本身可用，但仍被全站重側欄與密集導覽拖亂視覺節奏。

## 推薦方案

### 1. Header 收斂

- 保留：
  - Logo
  - 搜尋欄
  - 購物車
  - 會員入口
- 收起或移除：
  - top utility bar 內大部分細連結
  - header 下方整條橫向分類列
- 保留一個簡單頁面骨架：
  - header 主列
  - 內容區
  - footer

### 2. 左欄只做分類

- `sidebar-left` 改成單一責任：
  - 只顯示商品分類樹
- 分類行為：
  - 預設只顯示頂層分類
  - 點擊展開才顯示子分類
  - 同時間最多展開 1 至 2 個大類
  - 當前分類頁自動展開對應父類並高亮
- count 保留，但用淡色小字處理，避免每行都搶視線
- 左欄移除：
  - 會員區
  - 公告/活動 banner

### 3. 右欄降權

- `sidebar-right` 不再作為全站固定骨架的一部分。
- 首頁：
  - 右欄移除
- 商品列表頁：
  - 右欄移除
- 商品詳情頁：
  - 右欄移除
- 最近瀏覽或推薦模組如需保留，移入主內容區較後位置，而不是固定側欄。

### 4. 首頁改為導購頁

- 首頁版面從三欄轉成「左欄簡化分類 + 中間主內容」。
- 中間主內容只保留高價值區塊：
  - 主 banner / 活動圖
  - 熱門商品或排行榜
  - 最新上架
  - 精選分類入口
- 不再在首頁呈現完整分類樹、會員區、右欄推薦堆疊。

### 5. Products / Product 頁分工

- `/products`
  - 保留左欄摺疊分類
  - 主內容集中商品格仔、排序、分頁
  - 手機版分類 chips 可保留，但桌面不再重覆完整分類導航
- `/product/:id`
  - 保留左欄分類導覽
  - 移除右欄
  - 相關商品留在內容底部
  - 商品資訊與購買區保持為頁面主焦點

## 實作範圍

- `views/partials/header.ejs`
  - 收斂 header 結構
  - 移除橫向分類列
- `views/partials/sidebar-left.ejs`
  - 重寫為摺疊分類樹
  - 移除會員/公告模組
- `views/partials/sidebar-right.ejs`
  - 降權或不再於上述頁面 include
- `views/index.ejs`
  - 改成導購式首頁
- `views/products.ejs`
  - 對齊新骨架與 spacing
- `views/product.ejs`
  - 移除右欄依賴，保留主內容與左欄

## 互動規格

### 左欄分類摺疊

- 桌面版：
  - 點擊頂層分類標題切換展開/收起
  - 若分類有子項，顯示箭嘴 icon
  - 當前分類所屬父類預設展開
- 手機版：
  - 不強制沿用左欄
  - 產品列表頁保留簡化版分類 chips 或抽屜入口即可

### 當前分類狀態

- 透過 `selectedCategorySlug` 比對當前分類
- 若命中子分類：
  - 對應父類展開
  - 子分類項目高亮
- 若命中父分類：
  - 父類高亮並展開

## 驗收標準

- Header 唔再同時出現多組分類入口。
- 首頁唔再見到完整分類樹、會員區、右欄長模組堆疊。
- 左欄只負責分類導覽，並支援摺疊/展開。
- 商品列表頁可正常瀏覽父分類與子分類商品。
- 商品詳情頁仍正常顯示 `商品情報`、購買區與相關商品。
- 手機版至少保持可用，不會因收納分類而無法進入分類頁。

## 非目標

- 今次不重寫後端同步、分類資料模型或 SEO 結構。
- 今次不重做品牌系統或完整設計語言。
- 今次不新增大型前端框架或狀態管理工具。
- 今次以現有 EJS + Tailwind 結構整理為主，不做 SPA 化。

## 風險與注意事項

- 左欄摺疊需要小心處理 `selectedCategorySlug` 對應父子關係，避免當前分類未展開。
- 移除右欄後，要確認最近瀏覽與推薦模組仍有合理落點，不會完全消失造成功能倒退。
- Header 收斂後，原本 top utility bar 上的次要入口可能需要搬到 footer，避免功能失聯。
